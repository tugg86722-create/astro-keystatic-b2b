## 概要

現代のペイドソーシャル広告（Meta Ads、TikTok Ads、Google Performance Max）において、最も広く、かつ最も高くつく漏れは **クリック→LP到達ロス** です。標準的な Shopify ストアでは、広告をクリックしたユーザーの20%〜35%がページが描画される前に離脱します。広告購入側はクリエイティブの疲労やターゲティングのせいにしますが、本当の原因は最適化されていないフロントエンドのレイテンシと、描画をブロックするサードパーティスクリプトです。

### コアなアーキテクチャ対策

- **根本原因のフォレンジック診断**：Meta Graph API のアウトバウンドクリックとGA4の生のLPセッションを突き合わせ、モバイルWebViewにおける重大なアセットブロックを特定しました。肥大した外部タグマネージャーを解体し、重要でないピクセルをネイティブブラウザのアイドルコールバック（`requestIdleCallback`）の後ろに遅延しました。
- **コントラストとフラッシュ防止**：モバイルのアプリ内ブラウザは、ダークテーマのラグジュアリーストアフロントを開いたときに、視覚的に急激なホワイトフラッシュが走ることがよくあります。ダーク背景のトークンを含むインラインCSSを実装し、視覚的なカクつきをなくして即時バウンス率を18%下げました。
- **コントラストとフラッシュ防止**：モバイルのアプリ内ブラウザは、ダークテーマのラグジュアリーストアフロントを開いたときに、視覚的に jarring なホワイトフラッシュが走ります。ダーク背景トークンを含むインライン critical CSS を実装し、視覚的なカクつきをなくして即時バウンス率を18%下げました。
- **アトリビューションの精度**：クライアントサイドのゼロ遅延イベントディスパッチとMeta Conversions API（CAPI）のサーバーサイドイベントを組み合わせ、iOS 14.5+のトラッキング劣化後にイベントの完全性を回復しました。
